# How to Connect to the Cotality MCP

## Overview

To use Cotality data in Claude, add the Cotality MCP (UAT) as a custom connector, then sign in with a demo account. Setup takes about two minutes.

| Setting | Value |
| --- | --- |
| Server URL | `https://mcp-uat.cotality.com/mcp` |
| OAuth Client ID | `anthropic-claude-connector-uat` |

## Setup steps

1. In Claude, open **Settings**.
2. Go to **Connectors**.
3. Click **Add custom connector** and paste the server URL: `https://mcp-uat.cotality.com/mcp`
4. Open the OAuth settings, select the **last option**, and enter the Client ID: `anthropic-claude-connector-uat`
5. Save, then click **Connect**. When the Cotality sign-in page opens, log in with one of the demo accounts below.
6. After sign-in, the Cotality tools show as enabled under Connectors. Turn the connector on in a chat to start using it.
